# REBEKKA WEB STORE
Rebekka — Tienda Online de ModaPlataforma e-commerce desarrollada para la marca de moda Rebekka, especializada en la venta de ropa, calzado y accesorios. El proyecto incluye una experiencia de compra responsive y fluida para el cliente final, integrada con una API para la gestión de productos, inventario y procesamiento de pedidos.   Características PrincipalesFrontend (Angular):   Diseño responsive adaptado a computadoras, tablets y dispositivos móviles.   Catálogo de productos organizado por categorías (ropa, zapatos y accesorios) con filtros dinámicos.   Vista detallada de producto con selección de tallas, colores y variantes.   Carrito de compras y flujo de checkout optimizado.   Sistema de autenticación (registro e inicio de sesión de clientes) y consulta del historial de pedidos.   Backend & Base de Datos (PHP + MySQL):   API REST para la gestión y sincronización del catálogo, existencias y estados de compra.   Panel administrativo para el control de inventario, alta/edición de productos y administración de pedidos.   Integración de pagos mediante Mercado Pago y transferencias bancarias.   Módulo de envíos con captura de dirección y gestión de guías de entrega.   Stack TecnológicoFrontend: Angular, HTML5, CSS3/SCSS, TypeScript   Backend: PHP (API REST)   Base de Datos: MySQL   Pasarela de Pagos: Mercado Pago   API : Shopify
